# Clock App

## Overview

A simple desktop app built with Python and PyQt5 that has a digital clock and a stopwatch as seperate tabs.

## Features

* A real-time clock
* A stopwatch the has start, stop, lap and reset buttons

## Technology Used

* Python

## Packages

`PyQt5`: PyQt5 is a comprehensive set of Python bindings for Qt v5. It is implemented as more than 35 extension modules and enables Python to be used as an alternative application development language to C++ on all supported platforms including iOS and Android.

## Quick Start

### Prerequisites

* Git
* Python 3.14.3+

### Installation

#### 1. Clone the repo locally

```bash
git clone https://github.com/black-purple-jr/python-clock
```

#### 2. Create a virtual environement

```bash
python -m venv .venv
```

#### 3. Activate the virtual environement you created

##### * Linux / MacOS

```bash
./.venv/bin/activate
```

##### * Windows

```bash
./.venv/scripts/activate
```

#### 4. Select the interpreter for python from your virtual environement

##### * Windows / Linux

Ctrl + Shift + p

##### * MacOS

Cmd + Shift + p

and type Python: select interpreter

select the one prefixed with .venv

#### 5. Install the necessary package

```bash
pip install PySide6
```

#### 6. Run the main file

```bash
python main.py
```
